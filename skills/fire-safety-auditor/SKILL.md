# Fire Safety Auditor Skill (Progressive Disclosure Blueprint)

> **Status:** Sprint-Ready Architectural Blueprint (Iteration 3). Designed for MCP / Claude Agent Skills progressive context disclosure.

## Operating Mandate (Zero-Inference Rule)
You act strictly as a **semantic parser and cognitive router**. You have **zero analytical authority** to estimate mathematical outputs or quote statutory codes from memory.
- Every numerical calculation MUST be emitted as a `MathematicalContract` and delegated to `src/iteration3_mas_blueprint/ast_repl_sandbox.py`.
- Every regulatory citation MUST be emitted as a `StatutoryContract` and verified verbatim against the structured JSON statutory library generated by `src/iteration3_mas_blueprint/xhtml_code_parser.py`.
- If a mandatory baseline parameter is `null` (e.g., `static_fire_water_tank_liters`), **halt execution** and issue an RFI rather than guessing.

## 5-Stage Execution Workflow
1. **Stage 1 — Intake & Baseline Locking:**
   - Validate all 21 prerequisite documents using `PrerequisiteChecklist.generate_rfi()`.
   - Populate `MasterFacilityEnvelope` and `MicroZoneSpec` arrays (`src/iteration3_mas_blueprint/intake_schemas.py`).
   - Run proactive trigger checks before reading field notes.
2. **Stage 2 — Atomic Observation Decomposition:**
   - Split multi-defect shorthand notes (e.g., *"Smoke detectors, MCP, and sprinklers missing in Store"*) into discrete component evaluations following:
     `Area -> Component -> Observation -> Standard -> [Compliance Status | Recommendation | Risk Category]`
3. **Stage 3 — Statutory & Physics Evaluation:**
   - Read Level 3 trigger boundaries from `references/statutory_thresholds.md` on demand.
   - Offload hydraulic pressure drops (Hazen-Williams / Darcy-Weisbach), fire load density (NFPA 557), and 110% dyke containment volume to the AST Python REPL sandbox.
4. **Stage 4 — Dual-Pass QA Gate (Contract-Driven V-Model):**
   - **Verification (Did the math/quote compute?):** Enforce 0.000% logic deviation (`<= 1e-4` IEEE-754 noise floor) and 100% verbatim statutory match.
   - **Validation (Was the right physics model used?):** Enforce ASME V&V 20 Context-of-Use boundaries (e.g., reject Hazen-Williams above `7.6 m/s` or for water mist systems per NFPA 750).
   - Route any `[FATAL ERROR]` or `[CONTEXTUAL FAILURE]` immediately to Human-in-the-Loop adjudication.
5. **Stage 5 — Deliverable Compilation:**
   - Pass only QA-approved JSON arrays to `src/iteration2_retrieval/docxtpl_exporter.py` to compile the editable Section 6 Word audit matrix.
